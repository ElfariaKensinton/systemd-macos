macOS service manager

systemd-macos

A systemd-like service manager for macOS, implemented natively in Swift with systemd, systemctl, journalctl, service unit files, drop-ins, runtime edits, and LaunchDaemon bootstrapping.

curl -fsSL https://raw.githubusercontent.com/ElfariaKensinton/systemd-macos/main/scripts/install.sh | bash

The release installer downloads an architecture-specific GitHub Release, verifies its SHA-256 checksum, installs the binaries and shell completions, creates the unit/state directories, and registers the daemon with launchd.

  • macOS 13+ and Swift 5.10+
  • Apple Silicon and Intel release builds
  • systemctl edit with persistent and runtime drop-ins
  • status pager support with less -R -F -X
  • Project-local service logs exposed through journalctl

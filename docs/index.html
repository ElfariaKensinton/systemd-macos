macOS service manager

systemd-macos

A systemd-like service manager for macOS, with systemctl, journalctl, unit files, drop-ins, runtime units, and LaunchDaemon integration.

curl -fsSL https://elfariakensinton.github.io/systemd-macos/install.sh | bash

The installer downloads the latest release for your Mac, verifies its SHA-256 checksum, installs the binaries, unit directories, shell completions, and LaunchDaemon, then starts the daemon.

GitHub Releases Install script

Requires macOS and sudo access.
